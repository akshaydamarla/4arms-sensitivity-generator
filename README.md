# 🔥 4ARMS Sensitivity Generator

A modern and dynamic Free Fire sensitivity generator built using React + Vite that generates optimized sensitivity settings based on the user's device performance, display size, touch response, gameplay conditions, and sleeve usage.

# 🧠 How It Works

The sensitivity engine dynamically calculates values using:

- Device performance tier
- Touch responsiveness
- FPS smoothness
- Display size
- Sleeve friction adjustments

This allows every device to generate unique and realistic sensitivity values instead of static presets.

---

# 📊 Sensitivity System

The generated sensitivity values range between:

```txt
0 - 200
```

The generator intelligently adjusts:
- Higher sensitivity for no-sleeve users
- Balanced drag values for midrange devices
- Stable values for low-end devices
- Faster response tuning for flagship devices

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/4arms-sensitivity-generator.git
```

Navigate into the project:

```bash
cd 4arms-sensitivity-generator
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
